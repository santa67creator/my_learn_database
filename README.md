# SAN — Obsidian Knowledge Vault

A personal knowledge base and study vault built with [Obsidian](https://obsidian.md/).

This English copy contains translated Markdown notes, translated note and folder names, course materials, diagrams, and reference documents about computer science and mathematics.

## Contents

- **Computer architecture and CPU basics** — x86, ARM, AVR, instructions, opcodes, registers, processor modes
- **Computer memory** — RAM, addressing, data types, endianness, alignment, and two’s complement
- **Information and communication technologies** — operating systems, HCI, databases, networks, and internet technologies
- **Mathematics** — probability, statistics, decision theory, optimization, game theory, and introductory AI mathematics

## Opening the vault in Obsidian

1. Install [Obsidian](https://obsidian.md/).
2. Clone this repository or download it as a ZIP archive.
3. In Obsidian, choose **Open folder as vault**.
4. Select the `san` folder.
5. Start with one of the navigation notes:
   - `Computer Science/00 MAIN MAP.md`
   - `Computer Science/Memory/MEMORY CHAPTER.md`
   - `MATH/Probability & Statistics/00 Contents.md`
   - `MATH/Decision Theory/00 Contents.md`

The notes use Obsidian wiki-links to connect related topics.

## GitHub preview
