# Sigmoid Function

$$\sigma(x)=\frac{1}{1+e^{-x}}$$

The sigmoid function maps any real-valued input to a value between 0 and 1. It is commonly used to represent probabilities in binary classification and as an activation function in early neural-network models.

Its derivative is:

$$\sigma'(x)=\sigma(x)(1-\sigma(x))$$
