The addresses at which the processor accesses memory are set by programs during their execution. But if they could access any location in memory, this would cause a bunch of security problems.
Therefore, the address that the program sets and the real address of the cell in memory can be very different.
==This system is called the address translation mechanism.==

------
To understand how it works, you should first understand the operating modes of the processor.
==The processor can operate in several modes.==
#### The first mode is called real address mode. 
— This is a 16-bit mode into which the processor switches immediately after turning on the computer. 
 - It is called that because the address generated by the programs is real and does not require any additional transformations.
![[Pasted image 20261019112803.png]]
#### The second mode is called protected - This is a 32-bit mode, which can only be switched to from the real addresses mode.
