## SPECIAL PURPOSE REGISTERS - 
target some specific content in them.![[Pasted image 20261002150935.png]]
For example:
#### in segment registers (SS, CS, DS) 
memory addresses are stored. 

#### Registers for working with the stack (BP, SP) 
point to the start of the frame and the top of the stack.

#### Flag registers (FLAGS) 
contain various bits that reflect the state of the result of the previous operation.

#### Command Instruction Pointer (IP) 
contains the address of the command to be executed next, and so on.
