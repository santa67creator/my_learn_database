## Information and communication technologies

Lecture notes for the course “Information and communication technologies”: computer architecture, operating systems, interfaces, databases, networks and the web.

## Themes

#### Computer and programs
- [[2_лекция_Введение_в_компьютерные_системы.pdf]] - hardware + software + data + user, von Neumann architecture, instruction cycle, memory hierarchy and cache, buses, multi-core
- [[3_лекция_Программное_обеспечение_Операционные_системы.pdf]] - system, application and tool software, OS as a resource manager, processes, virtual memory, kernel and virtualization

#### Man and interface
- [[4_Человеко_компьютерное_взаимодействие.pdf]] - HCI, Nielsen heuristics, Norman model, Fitts and Hick's laws, usability tests, accessibility

#### Data
- [[5_лекция_Системы_баз_данных_Управление_данными.pdf]] - DBMS, relational model, keys, normalization, SQL (CRUD), ER diagrams, ACID, indexes, SQL and NoSQL

#### Networks and Internet
- [[6 лекция Сети и телекоммуникации.pdf]] - network types (PAN–WAN), topologies, OSI model, IP and MAC, TCP and UDP, DNS, network security
- [[7 лекция Интернет-технологии.pdf]] - Internet and web, client-server, URL, HTTP and HTTPS, HTML/CSS/JS, cookies and sessions, PWA and SPA
