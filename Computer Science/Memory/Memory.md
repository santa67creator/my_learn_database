**Memory** is a computer component capable of storing various information.
==memory in computers is just numbers== 
a collection of numbers (binary data) 
- 💻 **Programs/code**
- 🖼️ **Images**
- ✉️ **Messages/letters**

**[[REGISTERS]]** — ==small cells memory which stay on core.==
very small and very fast storage locations inside the CPU. They temporarily hold data, addresses, and instructions the CPU is working with.
**so for what it's need? They are used to hold data and instructions that the CPU is currently working with.**

**CACHE** — ==it's storage for often usage core data.== 
small, very fast memory used to store frequently accessed data and instructions. The CPU can access cache much faster than RAM, so frequently used data can be retrieved more quickly.
*Cache have made of couple level* — ==in each every level core caching data, because core faster grab from cache, then always grab from ram. ==
*Cache is divided into levels such as L1, L2, and L3. L1 is generally the smallest and fastest, while L3 is generally larger and slower.*

**[[RAM]]**  — This is random-access memory (RAM) that temporarily stores data from currently running programs and processes open on a computer, phone, or tablet
